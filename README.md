# (Un)original Prusa Heated Drybox - Port and Modification for Arduino Nano ESP32

This project is intended to be used with the [(Un)original Prusa Heated Drybox](https://www.printables.com/model/883817-unoriginal-prusa-heated-drybox) but with an [Arduino Nano ESP32](https://docs.arduino.cc/hardware/nano-esp32/).

## Disclaimer

* _The code is still untested and under development._
* _Unsupervised use of electric heater might be dangerous. Use at your own risk._
